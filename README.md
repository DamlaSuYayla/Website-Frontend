# Personal Finance Tracker – Front End

The front end of a personal finance web app for tracking income and expenses, with weekly, monthly, quarterly and yearly analysis pages built with charts.

## Pages

| Page | Purpose |
| :--- | :--- |
| `LogIn.html`, `KayıtOl.html`, `ŞifremiUnuttum.html` | Log in, sign up, forgotten password |
| `Anasayfa.html` | Home dashboard |
| `Gelirlerim.html` | My income |
| `Harcamalarım.html` | My expenses |
| `HaftalıkAnaliz.html` | Weekly analysis |
| `Ocak.html` … `Aralık.html` | Monthly analysis (January–December) |
| `3AylıkAnaliz.html`, `6AylıkAnaliz.html` | 3-month and 6-month analysis |
| `YılSonu.html` | End-of-year summary |
| `Ayarlar.html` | Settings |

## How to view

No build step is needed: download the repository and open `LogIn.html` or `Anasayfa.html` in a browser.

## Tech stack

`HTML` · `CSS` · `JavaScript` · `Bootstrap` · `Chart.js` · `Feather Icons`

> The interface text is in Turkish. This repository contains the front end only, with no back end or database.
